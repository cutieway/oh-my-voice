# Style-to-reference A/B protocol v3

Status: **not run**. No blind judgments or acoustic analysis exist for taxonomy
v3. Do not claim Style improves character fit until these rows run.

History: `docs/style-ab-2026-11-02.md` covers the v2 mood/style experiment and
is not evidence for v3 fields.

## Invariants

- Identity text stays byte-identical in every paired take; only the Style clause
  changes. `identity_prompt_hash` must not move.
- One canonical reference WAV per cell, generated by VoiceDesign from
  `Identity + Style`; seed, prompt, model revision, and WAV hash are pinned.
- Missing fields are omitted, never defaulted.
- Only fields that pass citation/evidence and benchmark gates are rendered.
- Base ICL prompts come from the pinned reference and its exact transcript.

## Matrix

Identity profiles: at least three from different races/sexes/acoustic bands
(e.g. one compact/low, one average/mid, one large/low-mid). Seeds: at least
three per cell. Cells:

| Cell | Style input |
|---|---|
| `identity_only` | none |
| `register_only` | `register` only |
| `lexical_only` | `lexical_complexity` only |
| `sentence_only` | `sentence_complexity` only |
| `colloquial_only` | `colloquialism` only |
| `discourse_only` | `discourse_style` only |
| `combined` | all gate-passing fields |
| `renderer_baseline` | current renderer with combined fields |

Run the same matrix for the current renderer and candidate v3 renderer. Randomize
presentation order per judge; hide which cell produced each clip.

## Blind human judgments

Per clip, 5-point or pairwise:

- character fit;
- naturalness;
- stable identity across repeated renders;
- distinctiveness from the other profiles;
- overacting / caricature;
- consistency across multiple Base-generated lines for the same speaker.

## Acoustic diagnostics

Record F0 distribution, duration, timing, RMS, spectral characteristics, and
speaker embeddings per cell. Diagnostics explain a difference; they do not
replace human judgment, and no cell is optimized for pitch movement alone.

## Acceptance

A Style field renders in production only when:

- its benchmark evidence gate passed;
- its blind human preference does not reduce naturalness or stable identity;
- repeated-seed identity movement is acceptable;
- Base ICL output remains the same speaker across tested lines.

Until then, all Style fields are experimental and may be auditioned only.
