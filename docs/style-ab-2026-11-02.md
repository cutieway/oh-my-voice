# A/B: does the speech-style clause change a rendered reference?

> **Outcome 2026-11-03.** Listening preferred the styled render over the
> identity-only render for every sampled voice, and called the unstyled takes
> more AI-sounding. The mood layer was removed the same day, which also removes
> the interaction that dominates the four-arm addendum below. The style clause is
> now appended by default (`render_style()`), with no flag. This page is kept as
> measurement history; its "keep it off" recommendation is superseded.

Run: 2026-11-02. Five profiles, one reference take each, three cloned lines each.
Both conditions use the same reference script, the same profile, and the same
seed (the seed depends only on the voice id, then and now, so it is identical
whether or not the style clause is present). The only difference is the
instruct.

Rendered by the removed mood/`--with-style` flags, both gone since 2026-11-03

plus the style clause when the profile has style.

Characters were picked to span the label space rather than the voice space:

| Character | register | rhetorical_style | Why in the set |
|---|---|---|---|
| Gerolt | conversational | inquisitive | the only `plain` vocabulary and `high` colloquialism profile |
| wandering minstrel | formal | inquisitive | formal register with `complex` sentences |

## Measurements

Reference and line pitch are the median autocorrelation F0 of the runner;
`mfcc` is the RMS distance between 13 mean cepstral coefficients, an
instrument-agnostic timbre distance (higher = more change); `line |dF0|` is
the mean absolute per-line F0 difference.

| Character | ref F0 off → on | dF0 | line \|dF0\| | ref s off → on | ref mfcc | line/ref pitch dev off → on |
|---|---:|---:|---:|---:|---:|---:|
| wandering minstrel | 89.9 → 89.2 | −0.7 | 5.5 | 12.96 → 11.04 | 8.25 | 5.7 → 11.0 |
| Gerolt | 94.1 → 92.7 | −1.4 | 11.1 | 12.32 → 10.96 | 8.53 | 4.4 → 7.2 |
| Hildibrand | 167.8 → 128.0 | −39.8 | 30.5 | 11.52 → 10.56 | 3.55 | 12.2 → 4.8 |
| Erik | 134.8 → 175.2 | +40.4 | 21.5 | 11.84 → 11.76 | 4.96 | 11.9 → 27.1 |
| Knem Cheleim-In | 98.4 → 94.9 | −3.5 | 10.0 | 11.68 → 10.64 | 2.74 | 14.1 → 3.3 |

## What the numbers say

1. The clause is not ignored: adding ~110–140 characters of text moves the
   designed reference and every cloned line. The change is real, not a wash.
2. The direction is not controlled. Three characters move down (−0.7, −1.4,
   −39.8 Hz), one moves up (+40.4 Hz). Two characters whose style differs only
   in rhetorical label (`flowing` vs `emphatic`) move in opposite directions
   by ~80 Hz combined.
3. The magnitude is large enough to break casting. Hildibrand and Erik are
   both cast as `low_mid` masculine; the styled draws land at 128.0 Hz and
   175.2 Hz, i.e. bands apart. Nothing in the style clause asks for a pitch
   change. Hildibrand's arm carried a mood block in both conditions, so his
   shift is partly an interaction; the four-arm addendum below separates the
   two effects.
4. It shortens the reference. Off refs are 11.5–13.0 s, on refs 10.6–11.8 s:
   the clause occupies part of the generation budget.
5. Line-vs-reference pitch consistency is inconsistent across characters:
   Hildibrand improves (12.2 → 4.8 Hz) and Knem improves (14.1 → 3.3 Hz),
   while Erik degrades (11.9 → 27.1 Hz) and the minstrel degrades (5.7 → 11.0 Hz).
   There is no stable "more expressive and more consistent" direction.

## Judgement (superseded 2026-11-03)

> Kept for the record. The listening test on 2026-11-03 preferred the styled
> takes for every sampled voice, so the clause is now the default and the mood
> block that drove the interaction is gone.

The style clause should stay out of the render instruct by default.

The clause describes wording — register, vocabulary, sentence shape,
colloquialism, rhetorical habit. VoiceDesign conditions a voice, not a text
distribution, so the only channels it can influence are prosody and timbre.
The measurements show it does influence them, but as an uncontrolled
perturbation of the acoustic identity, including pitch, which casting already
decides deterministically from game data.

That is the wrong trade for this pipeline. Casting fields are evidence-backed
and reproducible; a style sentence appended after them reintroduces sampling
variance into the one layer that was designed to be deterministic. Anything the
listening test likes in the styled versions is better refactored into an
explicit casting field (pitch, intonation, pace, articulation) where it can be
justified from dialogue and reviewed once, than left as an unmodelled nudge.

The style labels themselves carry little between-character variance on this
set: register `neutral` 6/10, vocabulary `ordinary` 9/10, colloquialism `low`
9/10, sentence `mixed` 7/10; only rhetorical_style spreads (inquisitive 5,
emphatic 2, flowing 2, measured 1). Appending a clause that is nearly the same
for nine of ten characters and is causally ambiguous for the tenth buys little.

If the listening test finds a clear, repeatable preference for one condition on
a specific character, the actionable outcome is not "re-enable the style clause"
but "add the missing acoustic field that produced the preference".

This section is inference from measurements; the listening judgement is yours.

## Addendum 2026-11-02 — four-arm decomposition

The five-character A/B above changes two variables at once for Hildibrand
(his profile declares `happy`, so both arms carried the mood block). A second
measurement isolates the clauses on that one character at the same seed
`20670347`, the same reference script and the same three clone texts:

| Arm | Reference dir | Ref s | Ref F0 | Mean line F0 |
|---|---|---:|---:|---:|
| identity | `hildibrand-nomood-20261102` | 10.56 | 89.2 | 100.1 |
| identity + style | `hildibrand-idstyle-20261102` | 10.80 | 90.9 | 87.8 |
| identity + happy | `ab-off-all-20261102` | 11.52 | 167.8 | 162.7 |
| identity + style + happy | `ab-on-all-20261102` | 10.56 | 128.0 | 132.1 |

Additive decomposition against the identity arm:

| Channel | Style main effect | Mood main effect | Interaction | Total |
|---|---:|---:|---:|---:|
| reference F0 | +1.7 Hz | +78.6 Hz | −41.5 Hz | +38.8 Hz |
| mean line F0 | −12.3 Hz | +62.6 Hz | −18.2 Hz | +32.0 Hz |

Two conclusions replace part of the section above:

- Style alone is close to inert on this character (+1.7 Hz on the reference,
  −12 Hz on the lines), consistent with the three characters that moved by
  ≤3.5 Hz in the five-character run. The +40.4 Hz seen for Erik remains a
  style-alone effect; Hildibrand's −39.8 Hz is not.
- Mood is the dominant pitch mover, and the clauses are not additive. In the
  presence of a mood block, adding the style sentence shifts the reference by
  −39.8 Hz, while alone it shifts it by +1.7 Hz.

So the earlier wording ("style perturbs pitch up to 40 Hz") describes an
interaction, not a style main effect. The practical conclusion is unchanged
for style — it stays off until a listening test argues otherwise — but the
larger target is the mood block, which moves a `low_mid` masculine voice by
almost an octave on its own, while also deciding the character's pack archon.

With the mood layer removed, only the style channel remains; the measured style
main effect was small (+1.7 Hz on Hildibrand's reference). The listener preferred
it regardless.

Both measurements agree on one point: the render instruct is a single text
channel with no controlled semantics. Any block appended to it can move
acoustic identity, and the size of that move depends on what else is present.
